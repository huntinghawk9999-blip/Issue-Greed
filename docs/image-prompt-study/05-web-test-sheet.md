# 05. Venice 웹 테스트 순서표

프롬프트는 [03-conversions.md](03-conversions.md)에 있는 걸 그대로 복사해서 써요. 결과 이미지를 대화에 올려 주시면 아래 항목대로 비교할게요.

## 0. 먼저 화면에서 확인 (1분)

| 확인 항목 | 답 |
|---|---|
| 네거티브 입력란이 있나? (Lustify v8 / Chroma 각각) | |
| CFG 슬라이더가 있나? 범위와 기본값은? | |
| 스텝 슬라이더 범위는? (Chroma는 10이 상한인지) | |
| 시드 입력칸 위치 | |
| 프롬프트 향상 자동 켜짐 설정이 있나? → **끄기** | |
| 스타일 프리셋 → **없음** | |

## 1. 고정 설정

- 비율 9:16, 시드 하나로 고정(예: 12345), variants 1장
- Lustify v8: 스텝 30, CFG 4 (슬라이더가 있으면)
- Chroma: 스텝 10, CFG는 기본값

## 2. 생성 순서 (4장)

| # | 모델 | 프롬프트 | 네거티브 |
|---|---|---|---|
| 1 | Lustify v8 | Lustify A (원본 의도판) | Lustify 네거티브 |
| 2 | Lustify v8 | Lustify B (보정판) | Lustify 네거티브 |
| 3 | Chroma | Chroma A | Chroma 네거티브 |
| 4 | Chroma | Chroma B | Chroma 네거티브 |

여유가 있으면 같은 4장을 시드만 바꿔서 한 번 더 생성해 주세요. 시드 1개짜리 결과는 우연일 수 있거든요.

## 3. 장마다 볼 것

| 항목 | 기준 |
|---|---|
| 무릎 | 한쪽 무릎이 책상 위로 올라갔나? (B: 보는 사람 기준 왼쪽) |
| 손 | 손 위치가 자연스럽나? (B: 무릎 위 / 책상 짚기) |
| 발 | 발목이 꺾이거나 발가락이 틀어졌나? |
| 노트북 | 카메라 쪽에 있고, 몸 아래쪽을 일부 가리나? |
| 피부 | 얼굴과 몸의 질감이 같나? 플라스틱처럼 매끈한가? |
| 조명 | 창 쪽 역광 + 얼굴에 빛이 있나? 과노출인가? |
| 전체 | 사진 같나, AI 그림 같나? |
